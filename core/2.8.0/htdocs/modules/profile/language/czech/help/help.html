POPIS

Modul Profil slouží ke správě vlastních polí uživatelského profilu.

INSTALOVAT/ODINSTALOVAT

Nejsou nutná žádná zvláštní opatření, postupujte podle standardního instalačního procesu – rozbalte složku /profile do adresáře ../modules. Nainstalujte modul přes Správce -> Systémový modul -> Moduly.

Podrobné pokyny k instalaci modulů jsou k dispozici v Návod k obsluze XOOPS

NÁVOD K OBSLUZE

K nastavení tohoto modulu potřebujete:

  • Nakonfigurujte své preference pro modul (viz ‚Předvolby‘) a volitelně blok Profil, pokud jej hodláte používat (viz ‚Blokování‘).
  • Upravte existující kategorie nebo přidejte nové.
  • Upravte stávající pole nebo přidejte nová. Zde můžete určit, která pole budou viditelná v které kategorii a zda budou viditelná při registraci uživatele.
  • Definujte pořadí kroků registrace.
  • A nakonec můžete nastavit oprávnění pro jednotlivá pole - která jsou upravitelná, která lze vyhledávat.

Opatření proti spamu

Chcete-li minimalizovat registrace spamu, proveďte následující:

  • přejděte do modulu Protector v Admin, přejděte na Předvolby a poté dole na tuto možnost: "Zastavit spam ve fóru" Kontroluje POST data proti spammerům registrovaným v databázi www.stopforumspam.com.
    Nastavte jej na "Ban the IP (no limit)"

  • v /class/captcha/config.php, ujistěte se, že je režim nastaven jako "text":

    return $config = array(
    'disabled' => false, // Zakázat CAPTCHA
    'mode' => 'text', // výchozí režim, můžete si vybrat 'text', 'image', 'recaptcha' (vyžaduje klíč API)
    'name' => 'xoopscaptcha', // název captcha
    'skipmember' => true, // Přeskočit kontrolu CAPTCHA pro členy
    'maxattempts' => 10, // Maximální počet pokusů pro každou relaci
    );

  • V modulu Profil přejděte do Správce a v základním kroku na adrese:
    /modules/profile/admin/step.php?id=1
    nastavte "Uložit po zastavení" na "Ne"


  • V Předvolbách profilu nastavte možnost "Použít Captcha po druhém kroku registrace" na "Ano" (je výchozí)
